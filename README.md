This project demonstrates the end-to-end management of an industrial-decarbonisation Startup Showcase, including programme planning, startup screening, stakeholder mapping, relevance-based matchmaking, event execution and post-event outcome tracking. 
An additional post-money valuation model demonstrates how a potential equity investment arising from the showcase could affect founder ownership, investor ownership and dilution. 
The valuation model is an optional post-showcase tool and is not used to rank or select startups.
